# דקל — משקפיים

חנות משקפיים להדגמה. דף HTML אחד, בלי תלויות ובלי תמונות חיצוניות.

- 18 דגמים ב-5 קטגוריות: ראייה, שמש, סינון מסכים, ילדים וספורט
- כל זוג משקפיים מצויר ב-SVG לפי צורת מסגרת וצבע — אין קבצי תמונה
- עגלה מלאה: כמויות, הסרה, חישוב משלוח (חינם מעל ₪300), נשמרת ב-localStorage
- סינון לפי קטגוריה, מיון לפי מחיר או שם, וכרטיס מוצר עם מפרט

אתר הדגמה: כפתור התשלום מציג סיכום בלבד. אין גבייה ולא נאספים פרטי אשראי.
